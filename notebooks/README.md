# notebooks/

`hwo_target_evidence_colab.ipynb` is a thin, Colab-ready walkthrough backed
entirely by `hwoevidence` package functions. It installs the package from
GitHub, fetches both live catalogs (works on Colab's default networked
runtime, no credentials needed), builds the evidence matrix, and plots the
per-category completeness bar chart shown in the README. Runtime: under a
minute (164 NASA Exoplanet Archive rows plus ~160 individual VizieR
queries).
